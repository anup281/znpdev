ZNP Development v5.3.4 - Assign Project Team Read-Only Vendor Details Hotfix

INSTALLATION
1. Upload the contents of this ZIP to the website root.
2. Replace dev/project_team.php when prompted.
3. No installer or database changes are required.

CHANGES
- Renames Assign Vendor to Assign Project Team.
- The dropdown now displays Trade — Company.
- Selecting a trade automatically fills Company, Primary Contact, Phone, and Email.
- Vendor details are read-only and come from the Vendor Directory.
- Project Team assignments no longer copy editable vendor contact information.
- Notes remain optional.
- Supports the same company being assigned separately for multiple trades.
