ZNP Development v5.3.3 - Construction Portal Stabilization

INSTALLATION
1. Upload and overwrite the included files at the website root.
2. Sign in as an Administrator or Super Administrator.
3. Visit /install_v5_3_3.php.
4. Hard-refresh the Construction Portal on mobile.

CHANGES
- Native, reliable mobile header menu.
- Persistent bottom navigation: Schedule, Daily Log, Vendors, Tasks, More.
- More menu: Plans & Documents, Expenses, Photos, Calendar.
- Add Vendor and Assign Vendor controls now open without depending on JavaScript.
- Vendor page mobile layout no longer forces horizontal scrolling.
- External Construction Portal interaction controller added as progressive enhancement.
- No database schema changes.
